# Smart GIF Creator using Python

A simple and colorful Python-based web application for creating GIFs from images.

## Features

- Create GIFs from multiple images
- Simple and attractive user interface
- Upload and process images
- Generate animated GIF output
- Python-based GIF processing
- Easy-to-use interface

## Technologies Used

- Python
- Streamlit
- Pillow
- HTML/CSS
- Git & GitHub
