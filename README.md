**Smart GIF Creator using Python**

A colorful and user-friendly Python web application that allows users to create animated GIFs from multiple images.

**📌 Project Overview**

Smart GIF Creator using Python is a mini-project developed to simplify the process of creating animated GIFs. Users can upload multiple images, process them, and generate an animated GIF through an easy-to-use web interface.
The project uses Python, Streamlit, and Pillow for image processing and GIF generation.

**✨ Features**

Upload multiple images
    
Create animated GIFs from images

Simple and attractive web interface

Image processing using Pillow

Automatic GIF generation

Download generated GIF output

Beginner-friendly project structure

Modular GIF processing engine

**⚙️ Installation**

1. Clone the repository

git clone https://github.com/Gomathi0305/Smart-GIF-Creator.git 

2. Open the project folder

cd Smart-GIF-Creator 

3. Install the required packages

pip install -r requirements.txt 

**▶️ How to Run**

Start the Streamlit application using:
streamlit run app.py 
The application will open in your web browser.

**🔄 How It Works **
Upload Images ↓ Image Processing ↓ GIF Generation ↓ Animated GIF Output ↓ Download GIF
